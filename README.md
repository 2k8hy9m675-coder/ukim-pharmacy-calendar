# UKIM Pharmacy Calendar V1

This is a separate project. It does not modify your personal `pharmacy-calendar`.

## Features
- Programme + semester selection
- Multiple subjects
- Separate group for every subject
- Subjects can be mixed across semesters
- Dynamic personal `.ics` subscription URL
- Consecutive academic hours are merged

## Deploy frontend
Upload all files to the root of `ukim-pharmacy-calendar`.
Settings → Pages → Deploy from branch → main → /(root).

## Deploy dynamic calendar backend
GitHub Pages is static, so each student's unique subscription is generated by `worker.js`.

1. Create a free Cloudflare account / sign in.
2. Workers & Pages → Create → Worker.
3. Paste all of `worker.js` into the Worker editor and Deploy.
4. Copy your `https://....workers.dev` URL.
5. Edit `app.js` in GitHub and replace:
   `PASTE_YOUR_WORKER_URL_HERE`
   with that URL (no trailing slash).
6. Commit.

Your public GitHub Pages site can then generate a different live subscription URL for every student.
